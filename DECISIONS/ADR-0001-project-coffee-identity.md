# ADR-0001: Project Coffee identity

Date: 2026-07-02
Status: Accepted

## Context

The project could be defined as a Cursor setup, Cline workflow, OpenRouter routing system, or custom AI agent. That would make the project fragile because tools and models change rapidly.

## Decision

Define Project Coffee as a personal AI operating system and engineering philosophy that can use Cursor, Cline, Continue, OpenRouter, Nemotron, Claude, Codex, or future tools without being defined by them.

## Consequences

- Coffee documentation is tool-agnostic.
- Tool-specific files are implementation adapters.
- The durable assets are memory, knowledge, recipes, evaluations, and governance.
- The project can evolve without being renamed or redesigned every time the AI ecosystem changes.
