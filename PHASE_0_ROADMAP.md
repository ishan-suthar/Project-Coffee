## Phase 0 exit criteria

Coffee is ready for Phase 1 when:

- Project identity is clear.
- Tool and model independence are explicit.
- Human authority and safety boundaries are documented.
- Barista's role is defined.
- Pantry and Brew Log structures exist.
- Roastery scorecards exist.
- Repository can be opened in Cursor and used by agents.
- The human can explain Coffee in one paragraph.

## Phase 1 preview

Phase 1 will implement the working daily AI coding environment:

- install and configure Cursor;
- connect OpenRouter;
- configure model choices;
- add Cursor rules;
- test Nemotron and other Beans;
- add Continue and/or Cline sidecars if useful;
- run a first model bake-off;
- build the first working Barista workflow.
