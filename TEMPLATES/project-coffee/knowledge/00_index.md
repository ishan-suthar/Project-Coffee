## Search Keyword Guidance

- Add words future-you is likely to search.
- Include acronyms, aliases, part numbers, feature names, and common mistakes.
- Put important terms in headings when possible.
- Keep one topic per note when the note is meant to be searchable.

## Safety Note

- Do not store secrets, credentials, API keys, tokens, SSH keys, OAuth blobs,
  private regulated data, production data, or local credential exports.
- Summarize large or binary documents before indexing them.
- Mark stale or uncertain notes clearly.
