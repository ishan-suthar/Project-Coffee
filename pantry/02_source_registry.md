## How to add a source

1. Assign a unique ID (e.g. `SRC-001`).
2. Record type: paper, datasheet, API doc, note, standard, etc.
3. Note original date and date added.
4. Set reliability: Bronze, Silver, or Gold.
5. Link to processed note in the appropriate Pantry subfolder.
