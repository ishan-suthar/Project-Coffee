# Pantry Glossary

Quick reference for Coffee terminology used in the Pantry.

For the canonical glossary, see `COFFEE_TERMINOLOGY.md` at the repository root.

## Core terms

| Term | Meaning |
| --- | --- |
| Pantry | Organized knowledge base for retrieval by Barista and specialists |
| Bronze | Raw source — imported, not yet summarized or validated |
| Silver | Processed note — summarized with source, date, and relevance |
| Gold | Trusted project knowledge — validated and frequently reused |

## Pantry file conventions

- Use metadata headers: title, source, date, freshness, reliability, tags.
- Label uncertainty and stale facts explicitly.
- Never store secrets or credentials here.
