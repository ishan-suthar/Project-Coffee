# Coffee Terminology

Version: v0.1 Phase 0 Draft  
Date: 2026-07-02

This glossary creates a shared language for Project Coffee. The names are intentionally memorable, but each maps to a practical engineering component.

| Coffee term | Meaning in Project Coffee |
| --- | --- |
| Project Coffee | The full personal AI engineering ecosystem. |
| Coffee Counter | The primary editor or operating surface. Cursor is the current default; VS Code or another IDE can replace it later. |
| Barista | The orchestrator persona that plans, routes, delegates, verifies, documents, and learns. |
| Beans | Models such as Nemotron, Qwen, DeepSeek, Claude, GPT, Gemini, or future models. |
| House Blend | The default model-routing policy for daily work. |
| Recipes | Reusable prompts, workflows, skills, checklists, and procedures. |
| Pantry | The organized knowledge base: documents, papers, datasheets, notes, standards, and project references. |
| Brew Log | Project memory, lessons learned, decisions, progress, active context, and learning history. |
| Roastery | Evaluation system for models, prompts, tools, and agents. |
| Tasting Notes | Scorecards and observations from model or workflow tests. |
| Coffee Ledger | Token, cost, time, and value tracking. |
| Spill Guard | Privacy, ignore rules, sensitive-file handling, and safety controls. |
| Decaf Mode | Read-only planning, review, analysis, and explanation. No file changes. |
| Espresso Shot | Small fast task with minimal context and minimal risk. |
| Cold Brew | Long-running careful task with planning, checkpoints, and verification. |

## Naming principles

- Coffee names should help memory, not obscure meaning.
- Every metaphor should map to a clear engineering role.
- If a term becomes confusing, clarify or retire it.
- Tools keep their real names in configuration; Coffee terms describe roles.

## Example sentence

> Barista used the House Blend to route an Espresso Shot through a cheap Bean, retrieved one document from the Pantry, updated the Brew Log, and added Tasting Notes to the Roastery.

Plain English translation:

> The orchestrator used the default routing policy to complete a small task with an inexpensive model, retrieved relevant context from the knowledge base, updated project memory, and recorded model performance.
