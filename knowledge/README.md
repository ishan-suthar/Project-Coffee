# Knowledge

Lightweight Project Coffee knowledge lives here.

This folder is the small, token-efficient Pantry surface for agents. Start with
`00_index.md` before reading larger project documents.

## Rules

- Read summaries before raw docs.
- Open only the source files needed for the current shot.
- Prefer local Markdown and committed project state.
- Do not store secrets, credentials, API keys, tokens, or private data here.
- Do not add RAG, embeddings, scripts, or automation unless a later Brew
  explicitly scopes that work.
